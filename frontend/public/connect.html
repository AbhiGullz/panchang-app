Gajaa Panchang

Connect an AI assistant

Look up daily Panchang, festival dates and local puja windows using the same calendar engine as this website.

The connector is read-only. It receives the city or coordinates, date and calendar options supplied by your assistant. It cannot access My Tithis, Sankalpa, or saved preferences. Share city names, not street addresses.

Connector address

https://gajaapanchang.org/api/v1/mcp

Use Streamable HTTP. No Panchang account or API key is required. Your assistant's own plan and permissions still apply.

OpenClaw

Add the address in the MCP configuration, using the Streamable HTTP transport.

{"mcp":{"servers":{"gajaa-panchang":{"url":"https://gajaapanchang.org/api/v1/mcp","transport":"streamable-http"}}}}

Merge into existing settings; don't replace them.
